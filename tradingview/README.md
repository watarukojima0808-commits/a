# 移動平均フォーキャスト（TradingView / Pine Script v6）

[`ma_forecast.pine`](ma_forecast.pine) — 移動平均が「この先どこを通るか」をチャートの右側に描くインジケーター。

## なぜ予測できるのか

移動平均（25日線なら過去25本の平均）の将来の値は、実はほとんど確定している。
たとえば5日後の25日線に使われる25本のうち、20本は**すでに確定した過去の足**で、
未確定なのはこれから増える5本だけ。つまり

> 「これから価格がどう動くか」を1つ仮定すれば、移動平均の通り道は一意に決まる

ということ。このインジケーターは、その仮定を4通りから選んで移動平均の先行きを引く。
価格そのものを当てるツールではなく、**価格の仮定を移動平均の動きに翻訳する**ツール。

## できること

| 機能 | 内容 |
|------|------|
| 移動平均の先行き | 短期・長期の移動平均を指定本数だけ先まで破線で描画 |
| クロス予測 | 予測区間内でGC/DCが起きる位置に「GC予測 5本後」とラベル表示 |
| 次足の分岐点価格 | 次の足がいくらで引ければ移動平均が横ばい／上向きになるかを逆算して水平線表示 |
| 窓の確定率 | 予測時点の移動平均のうち、何%が確定済みの足で決まっているか（SMAのみ） |
| 情報パネル | 現在値・N本後の予測値・向き・分岐点・クロス予測を右上に表示 |
| アラート | 「予測期間内にGC/DCの見込み」「3本以内にGC/DCの見込み」 |

対応する移動平均は SMA / EMA / WMA / RMA の4種類。

## 導入手順

1. TradingViewでチャートを開き、下部の **Pineエディタ** を開く
2. [`ma_forecast.pine`](ma_forecast.pine) の中身を全部コピーして貼り付け
3. **保存** → **チャートに追加**

Pine Script v6 で書いてある。無料プランでも動く（描画オブジェクトは最新足のみ再描画する作りなので軽い）。

## 設定項目

### 移動平均

| 項目 | 初期値 | 説明 |
|------|--------|------|
| ソース | close | 計算に使う価格 |
| 種別 | SMA | SMA / EMA / WMA / RMA |
| 短期の期間 | 25 | 日足なら25日線 |
| 長期も使う | ON | OFFにするとクロス予測も止まる |
| 長期の期間 | 75 | 日足なら75日線 |
| 実線の移動平均も描く | ON | 通常の移動平均の重ね描き |

### 予測

| 項目 | 初期値 | 説明 |
|------|--------|------|
| 予測する本数 | 10 | 何本先まで描くか |
| 将来の価格の置き方 | 横ばい | 下の4モード |
| 傾きの計算期間 | 10 | 「直近の傾き」モードで使う線形回帰の期間 |
| 1本あたりの変化率(%) | 0.0 | 「変化率」モードで使う |
| 目標価格 | 0.0 | 「目標価格まで直線」モードで使う |
| 想定した価格の推移も描く | ON | 仮定した価格パスを点線で表示 |

#### 価格の置き方4モード

| モード | 仮定 | 使いどころ |
|--------|------|-----------|
| **横ばい** | 現在値のまま動かない | 最も中立。「今の価格が続くだけで25日線がどう動くか」を見る |
| **直近の傾き** | 直近の線形回帰の傾きがそのまま続く | 今のトレンドが継続した場合のクロス時期を見る |
| **変化率(%/本)** | 毎足 x% ずつ動く | 「毎日1%下げたら何本でDCするか」といったストレステスト |
| **目標価格まで直線** | 予測本数をかけて目標価格まで直線で動く | 「決算で1,500円まで戻したら25日線はどこ」を確認 |

## 見方のコツ

- **横ばいモードで上向きなら追い風**。価格が動かなくても移動平均が上がっていくということは、
  窓から抜けていく古い足が今より安いという意味で、需給の重みが軽くなっている状態。
- **分岐点価格が現在値よりかなり上**なら、その日は多少上げても移動平均は下向きのまま。
  「5日線を上抜けたのに翌日から下がる」といった動きの正体はここにある。
- **窓の確定率**が高いほど予測はブレにくい。25日線で10本先なら60%が確定済み。
  期間より先の本数を指定すると確定率0%＝完全に仮定次第になるので、
  予測本数は期間の半分くらいまでに収めるのが無難。
- **クロス予測は「今の仮定が続いたら」の話**。横ばいモードでのGC予測日は
  「価格が今のままでもGCする日」なので、実際にはそれより早いか遅いかのどちらか。

## 注意事項

- 予測値はあくまで「置いた仮定が当たった場合の値」であって、相場の予言ではない。
- EMA / RMA は窓の外の価格も無限に効き続けるため、確定率の概念がない（パネルは「—」表示）。
- リアルタイム足は確定するまで値が動くので、予測も足が確定するまで揺れる。
- 予測本数を大きく、かつWMAを選ぶと計算量が増える。重い場合は本数を減らす。
