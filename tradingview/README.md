# エリオット波動 自動カウント インジケーター(TradingView用)

日足チャートでエリオット波動を分析するための TradingView インジケーター(Pine Script v5)です。

- スクリプト本体: [`elliott_wave_daily.pine`](./elliott_wave_daily.pine)

## 機能

- **波の自動検出**: ピボット(ジグザグ)で高値・安値のスイングを検出し、波として採用
- **推進波 1〜5 の自動ラベリング**: エリオット波動の基本3原則を満たすパターンだけをカウント
  1. 波2は波1の起点を割り込まない
  2. 波3は 1・3・5 波の中で最短にならない
  3. 波4は波1の価格領域に重ならない(ダイアゴナル用に許容設定あり)
- **修正波 A-B-C の自動ラベリング**: 推進5波完了後の3波を表示
- **進行中の波の暫定カウント**: 「第3波進行中?」「第5波進行中?」を `1?` `2?` のような ? 付きラベルで表示
- **フィボナッチ目標値**: フェーズに応じた目標ラインを自動描画
  - 第3波進行中 → 1.618×波1 / 2.618×波1
  - 第5波進行中 → 波1と等倍 / 0.618×(0→3)
  - 5波完了後 → 38.2% / 50% / 61.8% の押し・戻り水準
  - B波完了後 → C = A(等倍) / C = 1.618×A
- **上位度合いのジグザグ**: より大きな波の構造を太いグレー線で重ねて表示
- **状況パネル**: 現在のフェーズ(例:「上昇 第3波 進行中?」)と方向を右上に表示
- **アラート対応**: 「推進5波の完成」「フェーズの変化」でアラート設定可能

## 導入手順

1. TradingView でチャートを開く(**日足**を推奨)
2. 画面下部の「Pineエディタ」を開く
3. `elliott_wave_daily.pine` の中身を全てコピーして貼り付け
4. 「保存」→「チャートに追加」をクリック

## 主な設定

| 設定 | デフォルト | 説明 |
|---|---|---|
| ピボット感度 | 13 | 高値・安値の判定に使う左右のバー数。日足なら 8〜21 が目安。大きいほど大きな波だけを検出 |
| 最小スイング幅(%) | 4.0 | この割合以上動いたスイングだけを波として採用。個別株 4〜8%、指数 3〜5% が目安 |
| 波4の重複を許容 | オフ | ダイアゴナル(波4が波1に重なる形)もカウントしたい場合にオン |
| トランケーションを許容 | オフ | 波5が波3の終点に届かない「未達の5波」もカウントしたい場合にオン |
| 上位ピボット感度 | 34 | 上位度合いのジグザグの感度 |

ラベルが多すぎる/細かすぎる場合は「ピボット感度」や「最小スイング幅」を大きく、波を拾わなすぎる場合は小さくしてください。

## アラートの設定方法

1. チャート上部の「アラート」ボタンをクリック
2. 条件で「EW 日足」を選択
3. 「推進5波の完成を検出」または「フェーズの変化を検出」を選んで作成

## 注意事項

- ピボットは右側に「感度」本数のバーが確定してから成立するため、**直近の波のラベル確定には遅延があります**(デフォルト設定では約13本=約13営業日)。新しいピボットが確定すると直近のカウントが更新される、ジグザグ系インジケーター共通の性質があります。
- エリオット波動のカウントは本来主観的な分析手法であり、自動カウントは**あくまで参考値**です。
- 本スクリプトは分析補助ツールであり、投資助言ではありません。
