# SMMA_Rebound (MT5 EA)

15分足SMMA(20)へのタッチからの反発でエントリーするEA（ロング／ショート両対応、XAUUSD想定）。
値幅系の設定（タッチ許容幅・損切りバッファ・最大損切り幅）はATR倍率なので、ゴールドの値動きの大きさが変わっても自動で追従する。

## エントリーの種類（1本前の確定足で判定）

| 種類 | ロング | ショート |
|---|---|---|
| A. トレンド押し目/戻り (`trend`) | SMMA上向き中、SMMAまで押して反発 | SMMA下向き中、SMMAまで戻して反落 |
| B. ブレイク後リテスト (`retest`) | SMMAを上抜け後、一旦下げてSMMAで止まる | SMMAを下抜け後、一旦上げてSMMAで止まる |

## レンジフィルター

| # | 内容 | 初期値 |
|---|---|---|
| 1 | SMMAの傾きの強さ：5本でのSMMAの変化がATR×0.3未満なら「横ばい」としてAを見送り | ON |
| 2 | SMMAクロス回数：直近20本で終値がSMMAを3回超えてまたいでいたら見送り | ON |
| 3 | ADX：ADX(14)が20未満なら見送り | OFF |
| 4 | 上位足：1時間足SMMA(20)の向き（終値の位置＋傾き）と同じ方向だけ | ON |

## 決済
- 損切り: ロング=足の安値とSMMAの低い方 − ATR×0.2 / ショート=足の高値とSMMAの高い方 + ATR×0.2
- 利確: 損切り幅 × `InpRR`（初期1.5）
- 損切り幅が ATR×2 を超えるときは見送り

## 導入方法
1. MT5 → ファイル → データフォルダを開く → `MQL5/Experts/` に `.mq5` を置く
2. MetaEditorで開いてコンパイル（F7）
3. ストラテジーテスターでバックテスト → デモ口座で動作確認 → 本番
