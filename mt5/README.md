# SMMA_Rebound (MT5 EA)

15分足SMMAへのタッチからの反発でエントリーするEA（ロング／ショート両対応）。

## エントリーの種類（1本前の確定足で判定）

| 種類 | ロング | ショート |
|---|---|---|
| A. トレンド押し目/戻り (`trend`) | SMMA上向き中、SMMAまで押して反発 | SMMA下向き中、SMMAまで戻して反落 |
| B. ブレイク後リテスト (`retest`) | SMMAを上抜け後、一旦下げてSMMAで止まる | SMMAを下抜け後、一旦上げてSMMAで止まる |

Bは「抜けた直後でSMMAの傾きがまだ変わっていない」場面でも入れるようにするためのもの。
直近 `InpRetestLookback` 本以内にSMMAの反対側で確定した足があり、その後1本以上SMMAの抜けた側で確定していることが条件。

## 共通の反発条件
- ロング: 安値がSMMAにタッチ → 終値はSMMAより上 → 陽線（任意）→ 下ヒゲ比率（任意）
- ショート: 高値がSMMAにタッチ → 終値はSMMAより下 → 陰線（任意）→ 上ヒゲ比率（任意）

## 決済
- 損切り: ロング=足の安値とSMMAの低い方 − バッファ / ショート=足の高値とSMMAの高い方 + バッファ
- 利確: 損切り幅 × `InpRR`
- 損切り幅が `InpMaxSLPts` を超えるときは見送り

## 導入方法
1. MT5 → ファイル → データフォルダを開く → `MQL5/Experts/` に `.mq5` を置く
2. MetaEditorで開いてコンパイル（F7）
3. ストラテジーテスターでバックテスト → デモ口座で動作確認 → 本番
